# 2026-04-22 수정 요구사항: 가구매 제외 순이익 반영 및 손익 페이지 UX 정리

## 1. 배경

회사는 실적·판매수·리뷰 누적을 목적으로 외주 업체를 통해 일부 주문을 "가구매"(실사용자가 아닌 외주 구매자에 의한 가짜 구매)로 진행한다. 가구매로 발생한 매출은 실제 고객이 구매한 진짜 매출이 아니므로, 순이익 계산에 섞여 있으면 실제 수익성을 과대평가하게 된다. 따라서 손익 분석 화면에서 가구매 금액을 사용자가 수동으로 입력받아 최종 순이익 집계에서 제외할 수 있어야 한다.

가구매는 모든 날짜에 존재하지 않고, 시스템이 주문 데이터만으로 자동 식별할 수도 없기 때문에 **사용자의 수동 입력**이 필요하며, 비어 있을 수 있다(= 선택 입력).

## 2. 요구사항

### 2.1. 가구매 입력 UI (손익 페이지)

- 위치: `/profits` 페이지 헤더의 날짜 선택 입력 박스 **바로 오른쪽**
- 입력 형태: 숫자(원 단위). 음수·빈 값 허용, 빈 값은 `0`으로 처리
- 필수 여부: **선택(optional)**. 비워두어도 페이지가 정상 동작해야 함
- 스코프: 현재 화면에서 선택된 날짜(손익 페이지의 `dateTo`)에 대한 가구매 금액
- 저장 정책: 1차 스코프에서는 화면 상태로만 유지(새로고침 시 초기화 허용). DB 영속화는 후속 과업으로 분리

### 2.2. 손익 요약 박스 변경

가구매가 없는 날이 꽤 자주 있으므로 박스를 두 개로 쪼개지 않고 기존 **"예상 순이익" 박스 하나만 유지**하되, 가구매 입력 유무에 따라 표시 내용을 조건부로 바꾼다.

- 라벨은 기존과 동일하게 **"예상 순이익"** 유지
- 표시 값은 항상 **가구매까지 반영된 최종 순이익**을 보여준다
  - 가구매 입력이 비어있거나 0인 경우: 값 = `Σ(판매단위 VAT 차감 순이익) − 스토어 부담 배송비` (현재 계산식 그대로)
  - 가구매 입력이 있는 경우: 값 = 위 값 − 가구매 입력 금액
- 가구매 입력이 **있는 경우에만** 박스 하단(hint 영역)에 "가구매 데이터 제외 완료" 문구를 표시한다
  - 가구매 입력이 비어있거나 0인 경우에는 이 문구를 표시하지 않음(또는 기존 hint 유지)

### 2.3. 손익 페이지 헤더 설명 문구 제거

현재 `/profits` 페이지 헤더(`PageHeader`)에 노출되는 아래 문구를 **모두 삭제**한다.

- "판매단위 손익 분석" 타이틀 아래의 description 전체
- 즉, 다음 텍스트 전부 제거: `기간 2026년 4월 20일 - 2026년 4월 20일. 충돌 및 미매핑 행은 제외되며, 배송비 규칙이 확정되기 전까지 배송비는 상품 매출과 분리되어 관리됩니다.`

제거 후 헤더에는 eyebrow("손익"), 타이틀("판매단위 손익 분석"), 그리고 actions 영역의 날짜 선택 + 가구매 입력 UI만 남는다. 기간 표시가 정말 필요하다면 날짜 입력 자체가 그 역할을 대신하므로 문장 형태의 부연은 모두 치운다.

> 참고: 0421에서 추가한 상단 배송비 설명 배너(`선택한 날짜(...) 기준 배송비 계산 내역 ...`)는 본 요구사항의 제거 대상이 **아니다**. 이번에 지워야 하는 것은 `PageHeader`의 description 문장뿐이다.

## 3. 계산식 요약

```
기본 순이익  = Σ(판매단위 VAT 차감 순이익) − 스토어 부담 배송비   (기존 계산식 유지)

예상 순이익(박스 표시값)
  - 가구매 입력이 비어있거나 0일 때: 기본 순이익
  - 가구매 입력이 존재할 때:        기본 순이익 − 가구매 입력 금액
                                     + 박스 하단에 "가구매 데이터 제외 완료" 표기
```

## 4. 수용 기준

1. `/profits` 헤더에서 기간/충돌·미매핑/배송비 설명 문장이 모두 사라진다.
2. 날짜 입력의 오른쪽에 가구매 금액 입력 박스가 보이며, 비워둔 상태에서도 페이지가 정상 동작한다.
3. 기존 "예상 순이익" 카드의 라벨은 그대로 "예상 순이익"으로 유지된다(새 카드 추가 없음).
4. 가구매 입력이 비어있거나 0일 때: "예상 순이익" 값은 기존 계산식 결과와 동일하며, 별도의 "가구매 데이터 제외 완료" 문구는 표시되지 않는다.
5. 가구매 입력이 있을 때: "예상 순이익" 값이 입력 금액만큼 즉시 차감된 값으로 바뀌고, 박스 하단에 "가구매 데이터 제외 완료" 문구가 노출된다(입력 변경 시 실시간 반영).
6. 기존의 VAT 처리, 배송비 계산, 충돌/미매핑 제외 로직, 판매단위 행 표시는 변경되지 않는다.
7. 손익 상세 패널(우측)의 기존 섹션들(거래 요약, 주요 수치, 수수료 내역, VAT 구성, 배송비 컨텍스트, 제외된 항목)은 본 변경 범위 밖이며 그대로 유지된다.

## 5. 범위 외 (Out of Scope)

- 가구매 금액의 데이터베이스 저장 및 날짜별 이력 관리 (별도 후속 과업)
- 가구매의 자동 탐지, 태깅, 외주 업체 API 연동
- 대시보드 페이지의 "순손익(예상)" 카드 라벨/계산 수정 (이번 수정은 `/profits`에 한정)
- 판매단위 단위로 가구매를 분배하는 로직 (스토어·날짜 단위에서만 일괄 차감)
- 가구매 제외로 인한 세금·VAT 환원 처리
