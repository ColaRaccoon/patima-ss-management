# 0604 수동 매핑 쓰기 성능 개선 계획 - 목차

이 문서는 수동 매핑 저장 버튼이 15~20초 걸리는 문제를 단계별로 해결하기 위한 전체 목차다.

새 세션에서 작업을 맡길 때는 아래 단계별 파일 중 하나를 직접 지정한다.

예:

```text
document/0604_수동매핑_쓰기성능_1단계_기준측정.md 파일을 읽고, 서브 에이전트 개발자/평가자 방식으로 끝까지 작업해줘.
```

각 단계 파일은 스스로 실행 가능한 지침서이며, 시작 시 반드시 공통 지침 파일을 먼저 읽도록 되어 있다.

## 진행 원칙

- 앞 단계가 완료되지 않았으면 뒤 단계를 시작하지 않는다.
- 모든 단계는 서브 에이전트 2개를 사용한다.
  - 개발자 에이전트: 구현 담당
  - 평가자 에이전트: 결함 검토 및 재작업 지시 담당
- 평가자가 합격할 때까지 개발자 재작업과 평가자 재검토를 반복한다.
- 실 DB 변경, rawPayload 실제 삭제, destructive 명령은 사용자 승인 없이 실행하지 않는다.
